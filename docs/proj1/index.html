Images of the Russian Empire

Colorizing the Prokudin-Gorskii photo collection

01

Approach

Each glass plate stores three grayscale exposures in B, G, R order. I split it into thirds, kept blue fixed, and shifted green and red until they matched blue.

For each shift, I ignored a 10% border and scored only the interior. L2 adds squared pixel differences, so lower is better. Normalized cross-correlation (NCC) compares mean-centered, normalized images, so higher is better. I used NCC below.

Small JPGs search every displacement from −15 to 15 pixels. Large TIFFs use an image pyramid: shrink by half until small, find a coarse shift, double it at the next level, then search nearby. This keeps each image well under one minute.

03

Image-pyramid results

05

Better features: fixing Emir

Raw NCC fails because Emir’s blue robe has very different intensity across channels. I aligned gradient magnitudes instead, then applied those offsets to the original channels.

Gradient alignment removes the large double image. Colored outer strips come from scan borders and wrapped pixels; I did not implement automatic cropping.
